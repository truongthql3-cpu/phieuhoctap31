Kết nối dữ liệu với Google Sheet

Lưu trữ tự động kết quả làm bài của học sinh

Khi đã lưu URL, mỗi lần học sinh nộp bài hoặc giáo viên xác nhận điểm Câu 5, kết quả sẽ tự động ghi thành một hàng mới trong Google Sheet.

Mã Google Apps Script (Copy dán vào Apps Script): 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow([
      "Thời gian nộp", "Họ và tên", "Lớp", 
      "Điểm Câu 1", "Điểm Câu 2", "Điểm Câu 3", "Điểm Câu 4", "Điểm Câu 5",
      "Câu trả lời Câu 5", "Tổng điểm", "Số câu đúng hoàn toàn", "Thời gian làm bài", "Nhận xét", "Trạng thái chấm"
    ]);
  }
  sheet.appendRow([
    new Date().toLocaleString("vi-VN"), data.studentName, data.studentClass,
    data.q1Score, data.q2Score, data.q3Score, data.q4Score, data.q5Score,
    data.q5Text, data.totalScore, data.correctCount, data.timeTaken, data.comment, data.status
  ]);
  return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}
  1. Mở Google Sheet → Chọn Tiện ích mở rộng (Extensions) → Apps Script.
  2. Xóa mã cũ, dán đoạn mã trên vào và nhấn Lưu (Ctrl+S).
  3. Nhấn Triển khai (Deploy) → Tùy chọn triển khai mới → Chọn Ứng dụng web (Web app) → Mục Ai có quyền truy cập chọn Bất kỳ ai (Anyone) → Nhấn Triển khai và dán URL vào ô trên.
